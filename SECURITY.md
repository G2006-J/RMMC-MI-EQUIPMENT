# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues or discussions. Use GitHub's private vulnerability reporting feature for this repository when available. If it is unavailable, contact a repository maintainer privately through the hosting organization and include the affected file or workflow, impact, and steps to reproduce.

Allow maintainers reasonable time to investigate and prepare a fix before public disclosure. Do not include real user data, passwords, API keys, or other secrets in a report.

## Supported versions

Security fixes are developed for the latest version on the default branch. Deployments should apply reviewed database migrations in order and keep dependencies current.
